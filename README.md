# 📊 Sales Analysis Dashboard (Power BI)

## Project Overview

This project analyzes the Sample Superstore dataset using Microsoft Power BI to identify sales trends, profitable categories, top-selling products, and regional performance. The goal is to provide business insights that can support data-driven decision-making.

---

## Objectives

- Analyze overall sales and profit
- Identify top-performing product categories
- Compare sales across different regions
- Discover best-selling products
- Present findings through an interactive dashboard

---

## Tools Used

## Key Insights

- Total Sales exceeded **2.30 Million**.
- Total Profit reached approximately **286 Thousand**.
- Technology generated the highest sales.
- Sales performance varies across different regions.
- A small number of products contribute a significant portion of overall sales.

---

## Business Recommendations

- Increase investment in high-performing categories like Technology.
- Improve marketing efforts in lower-performing regions.
- Maintain sufficient inventory for top-selling products.
- Monitor regional performance regularly to identify growth opportunities.
